# 3D Coin Pusher Arcade System

このプロジェクトは、アーケードゲーム特有の「コイン落とし」体験を再現する3D物理シミュレーションゲームです。動的な物理挙動、スロットマシン演出、そしてフィーバーモードを搭載しています。

## 必要なセットアップ

1. **Unityバージョン**: 2022.3.x 以上を推奨します。
2. **TextMeshPro**: パッケージマネージャーから「TextMeshPro」がインストールされていることを確認してください。
3. **タグ設定**: `Tag Manager` に以下のタグを追加してください:
   - `Coin`
   - `ScoreZone`
   - `KillZone`
4. **自動生成機能**: 本プロジェクトはコードベースのプロシージャル生成を多用しています。シーンにオブジェクトを配置しなくても、実行時に自動的にUIや壁が構築されるよう設計されています。

## 主な機能

- **物理プッシャー**: サイン波による往復運動でコインを押し出します。
- **スロットマシン**: プッシャー上のトリガーにコインが入るとスロットが回転し、報酬（コイン連射や壁生成など）が与えられます。
- **プロシージャルUI**: UI要素が不足している場合、実行時に自動でUIを構築してフォールバックします。
- **エフェクト管理**: 外部アセットに頼らず、Procedural Particle Systemでリッチな演出を実現します。

## 操作方法

- 本プロジェクトのメインシーン（`Assets/Scenes/Main.unity`）を開き、再生ボタンを押してください。
- コインが自動的に管理され、物理挙動によって盤面から落ちたコインがスコアとして加算されます。

## 注意点

- `SoundManager.cs` の各オーディオ再生メソッドは現在空の実装になっています。実際のサウンドを統合するには `Resources` フォルダに適切な `AudioClip` を配置し、各メソッドを編集してください。
