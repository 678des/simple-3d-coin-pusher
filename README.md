# CoinPusherPro - 3Dコインプッシャーゲーム

## 概要
このプロジェクトは、Unityを使用した本格的な3Dコインプッシャーゲームです。スロットマシンや特殊演出、動的な物理制御システムを備えています。

## セットアップガイド
1. **プロジェクトを開く**: Unity 2022.3 LTS 以上でプロジェクトフォルダを開きます。
2. **シーンの設定**:
   - 新規シーンを作成し、床面や壁を配置します。
   - `GameManager` オブジェクトを作成し、`GameManager.cs` と `UIManager.cs` をアタッチします。
   - `GlobalPhysicsManager` オブジェクトを作成し、`GlobalPhysicsManager.cs` をアタッチします。
3. **コンポーネントの割り当て**:
   - 盤面の得点エリアには `ScoreZone.cs` を、左右の落下エリアには `SideLossZone.cs` をアタッチしてください。
   - コインのプレハブを作成し、`Coin.cs` をアタッチ後、`CoinSpawner` のインスペクターにドラッグ＆ドロップしてください。
4. **自動生成機能**:
   - エフェクトやスロットマシンのUIは、シーン実行時にスクリプト側で自動生成（プロシージャル生成）されます。特別なプレハブ準備なしで動作確認が可能です。

## 特徴
- **動的壁システム**: `SideWallsController` によるコインの横漏れ防止機能。
- **スロットマシン**: プッシャー上のタイミングを競うユニークな遊び。
- **プロシージャルUI/FX**: 事前配置不要で動的にUIやパーティクルを生成。
