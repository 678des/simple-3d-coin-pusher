# 3Dコインプッシャー・シミュレーター

このプロジェクトは、Unityで構築されたアーケードスタイルの「コインプッシャー」ゲームです。物理演算、動的なスロット演出、および自動化されたUI/エフェクトシステムを特徴としています。

## 🛠 プロジェクトの開き方

1. Unity Hubを開き、本プロジェクトのフォルダを選択します。
2. Unity 2022.3 LTS以降のバージョンでプロジェクトを開いてください。
3. プロジェクトが読み込まれたら、`Assets/Scenes` フォルダ内のシーンを開いてください。
4. シーン内にUIおよびマネージャーオブジェクトがない場合、スクリプトが実行時に自動生成（Procedural）する設計になっていますが、シーン上に空のGameObjectを作成し、各マネージャースクリプトをアタッチすることをお勧めします。

## ✨ 主要機能

*   **物理ベースのコイン制御:** `Coin.cs` により、コインの質量や回転、落下挙動をリアルタイムに制御します。
*   **プロシージャル・スロットマシン:** `SlotMachineController.cs` が自動的に3D掲示板とトリガーポケットを生成し、コイン投入によるボーナス抽選を行います。
*   **エフェクト自動生成:** `EffectsManager.cs` により、プレハブなしでパーティクル演出を即座に生成可能です。
*   **フィーバーモード:** スロットの当たり判定によって `GameManager.cs` 内のフィーバーゲージが増加し、ゲームがヒートアップします。

## ⚙️ セットアップ手順

### シーンの構築
- **GameManager:** 空のGameObjectを作成し `GameManager.cs` を追加してください。
- **CoinSpawner:** コインの発生位置にGameObjectを作成し `CoinSpawner.cs` を追加。InspectorからコインのPrefabを割り当ててください。
- **UI:** `Canvas` コンポーネントを持つGameObjectに `UIManager.cs` をアタッチしてください。

### 物理設定の注意
- コインの回収エリア（`ScoreZone`, `SideLossZone`）には必ず `Is Trigger` にチェックが入った `Collider` を設定してください。
- `PusherMovement` を使用するプッシャーオブジェクトには `Rigidbody` を追加し、`isKinematic` を有効にしてください。

## 📝 依存関係について
本プロジェクトは `TextMeshPro` パッケージに依存しています。もしテキストが表示されない場合は、Window > Package Manager からインポートしてください。
