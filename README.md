# 3D Coin Pusher Arcade System

このプロジェクトは、Unityで実装された高度な3Dコインプッシャーゲームのベースシステムです。物理挙動、スロットマシンミニゲーム、および動的な演出システムを含んでいます。

## 🎮 主な機能
- **物理プッシャーシステム**: サイン波による往復移動と、動的にインジェクションされるトリガーポケット。
- **スロットマシン**: プレイ中の興奮を高める3Dリール演出と報酬システム。
- **プロシージャル演出**: プレハブに依存しないパーティクル生成およびUI生成機能。
- **特殊コイン**: Standard, Gold, Giant, Bonusの4種類の属性を持つコイン。
- **壁・フィーバーシステム**: コイン投入を補助するサイドウォール昇降機能とフィーバーモード。

## 🚀 セットアップ方法
1. **プロジェクトを開く**: Unity 2022.3以降のバージョンでプロジェクトフォルダを開いてください。
2. **TMPの準備**: `Window > TextMeshPro > Import TMP Essentials` を実行し、UIコンポーネントが正しくレンダリングされるようにしてください。
3. **タグの確認**: インスペクターで、以下のタグが設定されていることを確認してください。
   - `Player`
   - `Coin`
   - `ScoreZone`
   - `KillZone`
4. **自動生成について**: 多くのUIやエフェクト管理はスクリプト実行時に自動生成されるため、特別な配置設定は不要です。そのままシーンを再生可能です。

## 🛠 開発者向けTips
- `GameManager`が全機能の司令塔です。ルールを変更したい場合はここを調整してください。
- 新しいエフェクトを追加したい場合は `EffectsManager` の `GenerateParticleBurst` を利用してください。
- スロットの確率を調整したい場合は `SlotMachineController.DetermineResult()` メソッド内の値を変更してください。
