# 3D Coin Pusher Arcade プロジェクト

このプロジェクトは、物理演算ベースの本格的な3Dコインプッシャーゲームです。動的な演出、スロットマシンシステム、手続き型エフェクト生成を備えています。

## 🚀 導入手順
1. Unity 2022.3 LTS以降でプロジェクトを開きます。
2. **TextMeshPro** がパッケージマネージャー経由でインポートされていることを確認してください。
3. `MainScene` を開きます。
4. シーン内の `CoinSpawner` オブジェクトに、使用するコインのプレハブとバンパーのプレハブをインスペクターでアサインしてください。
5. ゲームを開始すると、自動的にUIやエフェクト管理システムが構築されます。

## ✨ 主要機能
- **物理コインシミュレーション**: 重さや回転が異なるコイン（Gold, Giant, Bonus）が現実的な物理挙動をします。
- **スロットマシンシステム**: プッシャー上に配置されたポケットにコインを入れると抽選が開始されます。
- **動的演出**: パーティクルやカメラ揺れをスクリプトから自動生成するため、プレハブ設定の手間が最小限です。
- **フィーバーモード**: スロットの結果に応じて特殊モードが発動し、ゲーム性を高めます。

## 🛠 開発者向け注意点
- **自動構成 (Auto-Initialization)**: `EffectsManager` や `SlotMachineController` はシーン起動時に自動的に必要なコンポーネントをアタッチします。既存のシーンにこれらを手動配置する必要はありません。
- **UIのフォールバック**: `UIManager` は必要なUI要素（TextMeshPro）が欠けている場合、自動的にオーバーレイを作成してゲームが止まらないように設計されています。
- **物理演算**: `GlobalPhysicsManager` を使用して、ゲーム中に重力やタイムスケールを動的に変更することが可能です。
